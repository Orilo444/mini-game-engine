    Game code (JavaScript)

    API reference 
    scene(name, fn)        define a scene; the first one starts
go(name)               switch scene (applied at end of frame)
add({...})             create a game object, returns it
  x y w h rot scale flip color sprite text size layer
  tag solid body gravity vx vy grounded ui visible
  update(dt)           runs every frame, "this" is the object
obj.addComponent({name, start(), update(dt), render(ctx)})
obj.getComponent(name)   obj.destroy()   obj.touches(other)
find(tag)              all live objects with that tag
onCollide(tagA, tagB, (a, b) => {})
onUpdate(dt => {})     scene-level update
bg(color)              scene background
camera.follow(obj, followY=true)  camera.x .y .zoom
key.down(k) key.pressed(k) key.released(k)
  k: left right up down space enter a-z ...
mouse.x .y (screen)  .wx .wy (world)  .down  .pressed
play(sound, volume)  log(...)  rand(min, max)  W, H (640x360)

Physics: solid objects block objects with body:true.
ui:true objects ignore the camera (good for HUD text).
